# kangruli.web.id

Situs statis (HTML + CSS) untuk GitHub Pages.

## Langkah publikasi
1. Buat repositori GitHub baru, misalnya `kangruli-web`, lalu upload semua isi folder ini.
2. Buka Settings > Pages, pilih branch `main` dan folder `/ (root)`, lalu simpan.
3. Kolom Custom domain akan terisi dari file `CNAME`. Aktifkan Enforce HTTPS setelah sertifikat siap.
4. Di pengelola DNS domain Anda, tambahkan record CNAME dengan host `kangruli` dan target `USERNAME_GITHUB.github.io`.
5. Ganti `ca-pub-XXXXXXXXXXXXXXXX` dan `pub-XXXXXXXXXXXXXXXX` setelah AdSense disetujui.
6. Ganti alamat email di `kontak.html`.

## Menambah artikel
Salin salah satu file artikel, ubah isinya, tambahkan URL-nya ke `sitemap.xml`, lalu tambahkan tautan di halaman kategori dan beranda.

## Catatan AdSense
Pasang kode iklan hanya setelah situs disetujui. Jangan mengklik iklan sendiri dan jangan meminta orang lain mengkliknya.
